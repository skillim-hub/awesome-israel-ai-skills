# Contributing

## Add your skill / MCP server

Fastest: [open a submission issue](../../issues/new/choose) with your repo
link — we do the rest. Or send a PR adding one line to README.md in the
right category, format:

```
- [Name](https://github.com/you/repo) `MCP` — one-line description. *by [@you](https://github.com/you)*
```

**Criteria:** Israel-specific or Hebrew-specific · public repo · actually
works · is an agent skill, MCP server, or AI display tool (not a general
library).

We review within a few days. Your code stays yours, under your license —
this list only links and credits.

## Show you're listed

```markdown
[![Listed on Awesome Israel AI](https://img.shields.io/badge/listed_on-Awesome_Israel_AI-0B4EA2)](https://github.com/skillim-hub/awesome-israel-ai-skills)
```

## Corrections & removal

Wrong attribution, dead link, or you don't want your project listed?
Open an issue — removal requests are honored, no questions asked.
